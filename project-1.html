⚠️ Challenge: Synchronization Across Time Zones

Implementing real-time message delivery across multiple time zones required careful timestamp handling and conflict resolution.

✗ Solution: Developed a custom timestamp normalization system using UTC with automatic timezone conversion.

⚠️ Challenge: Offline Message Persistence

Ensuring messages persist when users jump between dimensions (network states) without data loss.

✗ Solution: Implemented Room database with Firebase sync and conflict resolution using vector clocks.

⚠️ Challenge: Battery Optimization

Maintaining real-time connectivity while respecting Android's battery optimization constraints.

✗ Solution: Used WorkManager for background sync and optimized WebSocket ping intervals.
